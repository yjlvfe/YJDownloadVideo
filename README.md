# 🚀 YJDownloadVideo

نظام متكامل واحترافي لتحميل مقاطع الفيديو، الصوتيات، وألبومات الصور من جميع منصات التواصل الاجتماعي وأي موقع ويب آخر، مع بوت تيليجرام تفاعلي فائق السرعة يدعم رفع ملفات حتى 2GB.

---

## ✨ المميزات الرئيسية

- **🌐 دعم شامل للمنصات والمواقع:**
  - تحميل من كافة شبكات التواصل الاجتماعي (YouTube, TikTok, Instagram, X/Twitter, Facebook, وغيرها).
  - دعم التحميل المباشر من مختلف مواقع الويب ومشغلات الفيديو عبر الإنترنت.
- **⚡ استجابة فورية للبوت (< 0.05 ثانية):**
  - عرض فوري لخيارات التحميل بمجرد إرسال الرابط دون أي تأخير أو انتظار.
  - خيارات واضحة ومباشرة: `فيديو / صورة` أو `صوت`.
- **📸 دعم ألبومات صور تيك توك (Photo Mode):**
  - إرسال السلايدات والصور كألبوم صور حقيقي عالي الدقة، مع إرسال المقطع الصوتي المرفق.
- **📦 إرسال مقاطع فيديو أصلية متدفقة (Native Streaming Video):**
  - إرسال المقاطع كفيديو متدفق مع صورة مصغرة وأبعاد ودقة أصلية حتى 2GB عبر خادم Telegram Bot API المحلي.
- **🔗 استقبال عدة روابط في رسالة واحدة:**
  - إمكانية وضع أكثر من رابط في نفس الرسالة، ويقوم البوت بمعالجتها وعرض لوحة التحكم لكل رابط بالترتيب.
- **⏱ إلغاء تلقائي ذكي:**
  - حذف أزرار التحكم وإلغاء المهام المعلقة تلقائياً بعد 5 دقائق لتفادي تراكم الطلبات.

## 🚀 التشغيل السريع (Plug-and-Play)

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/yjlvfe/YJSocialMediaDownload.git
   cd YJSocialMediaDownload
   ```

2. **إعداد متغيرات البيئة:**
   ```bash
   cp .env.example .env
   ```
   *قم بتعديل ملف `.env` وإضافة `TELEGRAM_BOT_TOKEN` ومفتاح `SECRET_KEY`.*

3. **تشغيل المشروع عبر Docker Compose:**
   ```bash
   docker compose up -d --build
   ```

النظام سيعمل تلقائياً بالكامل (Web API + Worker + Telegram Bot + Redis + Local Telegram Bot API Server).
