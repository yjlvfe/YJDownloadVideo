# YJSocialMediaDownload 🎬

بوت تيليجرام لتحميل الفيديوهات — أرسل رابطًا وسيحمّله لك فورًا بكل الجودات المتاحة.

بسيط وقوي: **مسار تحميل واحد** (yt-dlp) بدل الأنظمة المتعددة الطبقية، لأن كل نمط طلبات إضافي
يرفع شك يوتيوب ويسرّع حظر الـ IP.

---

## ✨ المميزات

| الميزة | الوصف |
|---|---|
| 🎯 **كل الجودات** | من 8K إلى 144p + الصوت — بلا سقف، حسب ما يوفره المقطع فعليًا |
| 🤖 **بوت تيليجرام** | رابط ← قائمة الجودات مباشرة ← شريط تقدم حي ← المقطع يوصلك ← **حذف فوري** |
| 🔄 **حماية من الحظر** | `/ip` يغيّر عنوان التحميل (VPN) + `/clear` يحذف الكوكيز — يوتيوب ما يقدر يمسكك |
| 📦 **حتى 2GB** | عبر خادم Bot API محلي (tba) — بدون حساب شخصي أو رقم جوال |
| 🗑️ **حذف فوري** | الملف يُمحى لحظة وصوله للمستخدم (ما عدا ملفات >2GB تبقى 24 ساعة لرابط التحميل) |
| ⚡ **معالجة متوازية** | حتى 10 مهام دفعة واحدة — بلا طابور |
| 💾 **HDD فقط** | تخزين مباشر على القرص — لا رام ولا تعقيد |

---

## ⚙️ الأوامر

| الأمر | الوظيفة |
|---|---|
| `/start` | الترحيب والتعليمات |
| `/ip` | عرض عنوان التحميل الحالي + زر «تغيير» (يجلب عنوانًا جديدًا مع إعادة محاولة تلقائية حتى يتغيّر فعليًا) |
| `/clear` | حذف كل ملفات الكوكيز بالكامل (لما الحظر يكون من الجلسة مو الـ IP) |

## 🧠 المعمارية

نظام Docker Compose من 6 حاويات:

```
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│  web        │   │  worker     │   │  bot        │
│  FastAPI    │   │  yt-dlp     │   │  PTB v21    │
│  واجهة + API│   │  (10 متوازية)│   │  polling    │
└──────┬──────┘   └──────┬──────┘   └──────┬──────┘
       └─────────┬───────┴───────┬────────┘
                 │               │
           ┌─────┴─────┐   ┌─────┴──────┐
           │  redis    │   │  tba       │
           │  طابور    │   │  Bot API   │
           └───────────┘   │  محلي 2GB  │
                           └────────────┘
   + cleanup (حذف تلقائي: منتهية + فاشلة + عالقة + أيتام)
```

| الحاوية | الدور |
|---|---|
| `web` | FastAPI — الواجهة + `POST /api/inspect` + `GET /download/<token>` (مقفول بباقي المسارات) |
| `worker` | يسحب المهام من Redis ويعالجها بالتوازي (yt-dlp + كوكيز + VPN) |
| `bot` | يستقبل الروابط، يعرض الجودات، يرسل الملفات، يحذف فورًا |
| `tba` | خادم Bot API محلي — يرفع حد الإرسال إلى 2GB |
| `cleanup` | حذف تلقائي دوري للملفات المنتهية والفاشلة |
| `redis` | طابور المهام |

### المسار الوحيد للتحميل

```
الرابط → yt-dlp (محاولة واحدة) → ملف
         ├── كوكيز المستخدم (اختياري — للمحتوى المقيد)
         └── خروج عبر NordVPN (حاوية VPN — IP يوتيوب غير محظور)
```

**لا مسارات متعددة ولا fallback ولا متصفح** — كل نمط طلبات إضافي = خطر حظر يوتيوب.

### التخزين

- SQLite في `data/yjdownload.db` — يسجل الطلبات والحالات فقط
- الملفات في `storage/<job_id>/` — مجلد لكل مهمة، يُحذف فورًا بعد الإرسال

## 🛡️ الحماية من حظر يوتيوب

يوتيوب يحظر الـ IPs التابعة للسيرفرات (Datacenter). الحل المُطبَّق:

- **NordVPN داخل Docker**: حاوية `nordvpn` (صورة bubuntux، NordLynx) وكل حاويات التطبيق
  (web/bot/worker/cleanup) تشارك شبكتها عبر `network_mode: service:nordvpn` —
  خرجها كله عبر VPN، **والهوست/SSH لا يمسّه شي إطلاقًا** (لا ip rule ولا iptables ولا routes).
- **اختيار تلقائي لأفضل IP**: `CONNECT=Germany` يتصل بأفضل سيرفر (أقل حمل) تلقائيًا.
- **تبديل تلقائي**: سكربت الهوست `rotate-vpn.sh` يختار أفضل سيرفر ألماني (أقل حمل، مختلف عن
  الحالي) من API نورد ويتصل عبر `docker exec` — cron كل 24 ساعة.
- **تبديل يدوي**: `/ip` ← زر «تغيير» (نفس الواجهة، المراقب على الهوست ينفذ الدوران).
- **شفاء ذاتي**: لو حاوية الـ VPN توقفت/انفجرت، المراقب يعيد تشغيل الحاويات المشاركة تلقائيًا
  (ولو سقط النفق — الحاويات ترجع تخرج مباشر: fail-open، لا انقطاع).
- **`/clear`**: حذف الكوكيز لما يكون الحظر من الجلسة

## 🚀 النشر

```bash
# 1) انسخ الإعدادات
cp .env.example .env
#   ولّد SECRET_KEY:  openssl rand -hex 32

# 2) شغّل الحاويات
docker compose up -d --build

# 3) بعد أي تعديل كود — نشر موحّد لكل الحاويات
bash deploy.sh
```

> ⚠️ **مهم**: أي تعديل على الكود يجب أن يصل لكل الحاويات (bot + worker + web) معًا.
> استخدم `deploy.sh` دائمًا — `docker compose up --no-build` يرجع الحاوية للصورة القديمة ويفقد التعديلات.

## 🔑 متغيّرات البيئة الأساسية (`.env`)

| المتغير | الوصف |
|---|---|
| `SECRET_KEY` | إجباري — قيمة عشوائية طويلة |
| `TELEGRAM_BOT_TOKEN` | توكن البوت |
| `TELEGRAM_BOT_API_BASE` | `http://tba:8081` — خادم Bot API محلي (يرفع حد الإرسال لـ 2GB) |
| `NORDVPN_TOKEN` | توكن خدمة NordVPN (يُستخدم داخل حاوية الـ VPN — من my.nordaccount.com) |
| `BASE_URL` | عنوان السيرفر العلني (لروابط التحميل) |
| `MAX_ACTIVE_JOBS_PER_IP` / `_TELEGRAM_USER` | الحد الأقصى للمهام النشطة |
| `MAX_DURATION_SECONDS` | `0` = مدة غير محدودة |

باقي المتغيّرات في `.env.example`.
