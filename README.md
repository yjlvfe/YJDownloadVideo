# YJSocialMediaDownload

نظام تحميل شامل للمحتوى من **كافة منصات التواصل الاجتماعي وأي موقع ويب آخر** عبر بوت تيليجرام وواجهة ويب بسيطة. أرسل الرابط، واختر نوع الملف، وسيصل إليك المحتوى مباشرة.

## ✨ المميزات

- **دعم شامل للمواقع**: تحميل الفيديوهات والصور والصوت من منصات السوشال ميديا وأي موقع ويب آخر يدعمه النظام.
- **استجابة فورية**: يظهر خيار التحميل مباشرة بعد إرسال الرابط.
- **خيارات نقية وواضحة**: زر **فيديو / صورة** وزر **صوت** فقط.
- **ألبومات صور تيك توك**: تُرسل الصور كصور حقيقية داخل ألبوم، مع إرسال الصوت المصاحب عند توفره.
- **رفع ملفات حتى 2GB**: عبر Local Telegram Bot API المضمّن في Docker Compose.
- **تحميل متوازٍ**: معالجة عدة مهام في الوقت نفسه.
- **واجهة ويب و API**: يمكن استخدام الواجهة أو نقاط API المتاحة إلى جانب البوت.
- **تنظيف تلقائي**: حذف الملفات المؤقتة والمنتهية تلقائياً.
- **تخزين محلي**: البيانات في SQLite والملفات في مجلد `storage/`.

> استخدم النظام فقط لتحميل المحتوى المسموح لك باستخدامه. لا يدعم النظام فك تشفير DRM أو تجاوز حماية المواقع.

## 🚀 تشغيل Plug-and-Play عبر Docker Compose

### المتطلبات

- Docker Engine
- Docker Compose v2 (`docker compose`)
- توكن بوت تيليجرام من [@BotFather](https://t.me/BotFather)
- بيانات Telegram API من [my.telegram.org](https://my.telegram.org) لتشغيل Local Bot API
- توكن خدمة NordVPN إذا كنت ستستخدم اتصال NordVPN المضمّن

### التشغيل لأول مرة

من مجلد المشروع نفّذ الأوامر التالية:

```bash
cp .env.example .env
openssl rand -hex 32
```

ضع الناتج في `SECRET_KEY`، ثم افتح `.env` وأدخل:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `NORDVPN_TOKEN` (عند تفعيل NordVPN)
- `BASE_URL` إذا كان السيرفر متاحاً من الإنترنت

بعد ذلك شغّل المشروع بأمر واحد:

```bash
docker compose up -d --build
```

سيتم بناء وتشغيل جميع الخدمات تلقائياً: البوت، الواجهة، العامل، Redis، التنظيف التلقائي، Local Bot API، واتصال VPN.

- الواجهة المحلية: `http://localhost:8000`
- سجلات الخدمات: `docker compose logs -f`
- إيقاف الخدمات: `docker compose down`
- إعادة التشغيل بعد تعديل الإعدادات أو الكود: `docker compose up -d --build`

### تحديث سريع

```bash
git pull
docker compose up -d --build
```

## 🤖 تجربة البوت

1. افتح البوت في تيليجرام واضغط `/start`.
2. أرسل رابط فيديو أو صورة أو ألبوم.
3. اختر **فيديو / صورة** أو **صوت**.
4. انتظر وصول الملف أو الألبوم مباشرة.

الأوامر المتاحة:

| الأمر | الوظيفة |
|---|---|
| `/start` | عرض الترحيب والتعليمات |
| `/ip` | عرض عنوان التحميل الحالي وإتاحة تغييره |
| `/clear` | حذف ملفات الكوكيز المخزنة |

## 🧩 الخدمات

| الخدمة | الدور |
|---|---|
| `bot` | استقبال الروابط وإرسال النتائج عبر تيليجرام |
| `web` | واجهة الويب و API |
| `worker` | تنفيذ مهام التحميل بواسطة yt-dlp و FFmpeg |
| `redis` | طابور المهام |
| `tba` | Local Telegram Bot API بحد رفع يصل إلى 2GB |
| `cleanup` | حذف الملفات المؤقتة والمنتهية دورياً |
| `nordvpn` | اتصال VPN اختياري لخروج مهام التحميل |

## 🔐 الإعدادات والملفات السرية

- `.env.example` قالب آمن للإعدادات فقط.
- أنشئ ملف `.env` محلياً ولا ترفعه إلى Git أو GitHub.
- لا تضع توكنات حقيقية أو مفاتيح خاصة داخل ملفات المشروع المتتبعة.
- ملفات قاعدة البيانات والتنزيلات والكوكيز مستثناة من Git تلقائياً عبر `.gitignore`.

للاطلاع على جميع المتغيرات، راجع [`.env.example`](.env.example).
