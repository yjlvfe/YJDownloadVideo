# YJDownloadVideo

أقوى برنامج تحميل فيديو — **أي رابط في العالم يحتوي فيديو يتم تحميله**.
ليس فقط السوشيال ميديا: أي صفحة، أي موقع، أي مشغّل.

## محرك الاستخراج الشامل (Universal Extractor)

ثلاث طبقات هجومية، كل فشل ينقلك للتالية:

| الطبقة | الأداة | ماذا تلتقط |
|---|---|---|
| **L1** | yt-dlp (2000+ موقع) | يوتيوب، تيك توك، إنستغرام، X، فيسبوك، تويچ، ريديت… + الماسح العام |
| **L2** | ماسح HTML | وسوم `<video>/<source>`، og:video، JSON-LD، إعدادات المشغّل في JS، روابط مباشرة mp4/webm/m3u8/mpd |
| **L3** | متصفح خفي (CDP) | أي مشغّل يعتمد JavaScript — يفتح الصفحة ويلتقط طلبات الوسائط من الشبكة، مع كوكيز الجلسة تلقائيًا |

الاستثناء الوحيد: البث المشفّر بالكامل (DRM مثل Netflix) لا يمكن فكّه دون كسر التشفير نفسه.

## الاستخدام الفوري (CLI)

```bash
python cli.py "https://أي-موقع/أي-صفحة"
python cli.py "https://..." -q 1080          # جودة محددة
python cli.py "https://..." -q audio        # صوت فقط
python cli.py "https://..." --list          # عرض المرشحين المكتشفين
python cli.py "https://..." -c cookies.txt  # كوكيز جلسة لمواقع تحتاج تسجيل دخول
```

## الويب + البوت

1. `cp .env.example .env` وضَع توكن البوت ومفاتيح API الخاصة بك في `.env`
2. `docker compose up --build` ثم افتح http://localhost:8000

أرسل أي رابط للبوت في Telegram → يستخرج الفيديو ويحمّله ويرسله لك — **حتى 2GB مباشرة** عبر خادم Bot API المحلي (`tba`)، بلا حاجة لربط أي حساب شخصي.

## ملاحظات

- الطبقة L3 تتطلب Chromium على الجهاز (مثبّت تلقائيًا داخل Docker).
- حاوية `tba` هي خادم Bot API الرسمي المحلي (tdlib) — ترفع حد إرسال البوت إلى 2GB.
- المقاطع تُحذف تلقائيًا بعد 24 ساعة (FILE_TTL_SECONDS) — لا تراكم على السيرفر.
- الاستخدام الشخصي للمحتوى الذي يحق لك الوصول إليه. لا تكسر DRM ولا تسرق محتوى.

## النشر على Vercel (وضع مُخفّض — اقرأ قبل)

Vercel منصة Serverless: **لا حاويات Docker، لا عمليات دائمة، مهلة دالة قصيرة**.
لذلك عند النشر عليه يعمل النظام تلقائيًا بـ"وضع Vercel" (`api/index.py` + `vercel.json`):

✅ **يعمل**: الواجهة، فحص الروابط، البوت عبر **Webhook** (تحميل + إرسال حتى 50MB)،
   وضع الصوت، زر MP3 (عبر ffmpeg مدمج من imageio-ffmpeg)، الحذف التلقائي (لا تخزين دائم أصلًا).
❌ **لا يعمل**: إرسال فوق 50MB (لا خادم محلي)، طبقة المتصفح الخفي، روابط تحميل دائمة.

**خطوات النشر:**
1. ارفع المشروع لمستودع GitHub خاص
2. في Vercel: Import Project ← اختر المستودع ← Framework: Other
3. أضف متغيرات البيئة من القسم أعلاه في `.env.example`
4. Deploy ← وبعد نجاح أول نشر، شغّل من جهازك:
   `WEBHOOK_URL=https://<مشروعك>.vercel.app/webhook/telegram uv run python -m app.setup_webhook`
5. أرسل أي رابط للبوت 🎬

⚠️ على الخطة المجانية مهلة الدالة 60 ثانية — المقاطع الصغيرة (ريلز/شورتس/تيك توك) تنجز عادة،
   الكبيرة قد تنقطع. الخطة المدفوعة (300s) مريحة. للنظام الكامل (2GB + متصفح) استخدم `deploy.sh` على أي سيرفر.
